# Car Price Prediction with Machine Learning

## 📌 Overview
This project predicts used car selling prices using historical vehicle data. It utilizes machine learning techniques to evaluate features such as original price, mileage, age, fuel type, transmission, and seller type to estimate market resale value.

## 🛠️ Project Structure
* `car data.csv` - The dataset containing vehicle details and historical prices.
* `car_price_prediction.ipynb` - Jupyter Notebook containing data preprocessing, model training, and evaluation.
* `README.md` - Documentation for the project.

## 🚀 Model & Performance
* **Algorithm:** Random Forest Regressor
* **R² Score:** ~0.954 (95.4% Accuracy)
* **Mean Absolute Error (MAE):** ~0.67 Lakhs

## ⚙️ Requirements & Libraries
* Python 3.x
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn

## 📝 How to Run
1. Open `car_price_prediction.ipynb` in VS Code or Jupyter Notebook.
2. Ensure `car data.csv` is located in the same directory.
3. Run all cells sequentially to view model evaluation metrics and predictions.
